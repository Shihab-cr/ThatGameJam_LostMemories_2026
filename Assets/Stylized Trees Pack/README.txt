===============================================================================================
                                    STYLIZED TREE PACK                      
===============================================================================================

A pack of stylized trees & bushes.

-----------------------------------------------------------------------------------------------
    FEATURES
-----------------------------------------------------------------------------------------------

    - Color with gradients
    - 40+ prefabs
    - LODs
    - Foliage & surface shader
    - 30+ noise textures
    - 10+ foliage textures

-----------------------------------------------------------------------------------------------
    INSTALLATION
-----------------------------------------------------------------------------------------------

    Refer to the website for up-to-date documentation:
        https://laplahce.com/docs/stylized-tree-pack

    Install via Package Manager
        1. Open Window → Package Manager.
        2. Find the Stylized Tree Pack package.
        3. Import it.

    Upgrade to your Render Pipeline
        1. Open **Tools → STP → Welcome Screen**.
        2. In the **Setup** tab, click the **Upgrade** button for your Render Pipeline & import it.

    Setup Universal Render Pipeline (URP) settings
        1. Go to Project Settings → Graphics & find the assigned Universal Render Pipeline Asset.
        2. Make sure Depth Texture is `ON`.

    For more information, refer to the website: 
        https://laplahce.com/docs/stylized-tree-pack
